# 数字卡牌游戏基础规则草案 v0.4

## 1. 游戏定位

本游戏为一对一数字卡牌游戏。

目前的核心规则由四部分组成：

* PP会随对局持续增长，没有固定上限。
* 玩家可以提前打出原本支付不起的手牌，用PP容量补足费用。
* 单位可以进化，进化资源能够通过职业玩法重新获得。
* 每副牌拥有一个公开的战备区，战备牌如何使用由卡牌本身决定。

其中最核心的是PP系统。

玩家不仅要考虑“这张牌值不值得这个费用”，还要考虑：

> 我是等到正常费用再使用，还是现在就把未来几个回合的资源拿来支付？

---

# 2. 基础数值

| 项目      | 暂定规则   |
| ------- | ------ |
| 主战者生命   | 25     |
| 起始手牌    | 4张     |
| 主牌组     | 30张    |
| 战备区     | 0～6张   |
| 手牌上限    | 9张     |
| 单位区     | 5格     |
| 策略区     | 3格     |
| 同名主牌组卡  | 最多3张   |
| 同名战备牌   | 最多2张   |
| 进化能量上限  | 4      |
| 主动进化消耗  | 2      |
| 每回合主动进化 | 最多1次   |
| 每回合战备部署 | 默认最多1次 |
| PP容量    | 无上限    |
| 每回合动用未来 | 默认最多1次 |

以上均为测试数值，后续根据实际对局调整。

---

# 3. 胜利条件

双方主战者初始拥有25点生命。

出现以下情况时，对局结束：

1. 一方主战者生命降至0或以下。
2. 一方主动投降。
3. 某张卡牌完成写明的特殊胜利条件。

双方在同一批效果结算后同时降至0或以下时，判定为平局。

特殊胜利不属于职业标配，只允许少数围绕它构筑的系列使用。

---

# 4. 牌组构成

每副牌由以下部分组成：

* 一名主战者。
* 30张主牌组卡牌。
* 0至6张战备牌。

## 主战者

主战者决定玩家所属职业。

职业主要决定：

* 可以使用的职业卡池。
* 进化能量的获取条件。
* 大致的资源倾向。

同一个职业可以存在多种完全不同的卡组系列。

主战者外观、皮肤和语音不改变规则。

现阶段不强制每名主战者拥有主动技能。

## 主牌组

同名卡最多放入3张。

主牌组可以包含：

* 职业卡。
* 符合构筑条件的通用卡。

通用卡的具体限制等首批卡池完成后再定。

## 战备区

战备区最多放置6张卡牌。

双方从游戏开始时便可以查看对方完整的战备区。

战备牌：

* 不会正常抽到手中。
* 不占用主牌组数量。
* 必须通过自身写明的部署条件使用。

现阶段不划分融合、仪式、共鸣等不同召唤类型。

所有从战备区进入场上的行为统一称为：

> **部署**

不同卡牌通过不同的部署条件形成自己的玩法。

---

# 5. 场地区域

## 单位区

最多存在5个己方单位。

单位区已满时不能让新的单位登场。

如果某次部署会先移除己方单位，只要支付代价后能够腾出位置，就可以进行该次部署。

## 策略区

最多放置3张策略区卡牌。

目前设施和伏策共同使用策略区。

策略区已满时不能继续放置新的策略区卡牌，除非通过效果先移走其中一张。

## 手牌

手牌上限为9张。

手牌已满时，新进入手牌的卡牌会公开，然后进入封存区。

## 墓地

以下卡牌通常进入墓地：

* 被破坏的单位。
* 正常结算完毕的法术。
* 被弃置的手牌。
* 被破坏的设施或伏策。

墓地对双方公开。

## 封存区

封存区属于正常卡牌循环之外的区域。

被封存：

* 不视为被破坏。
* 不触发遗言。
* 默认不能再次使用。

只有明确提到封存区的效果才能与其中的卡牌互动。

## 战备区

战备区始终公开。

普通战备牌从场上离开后默认进入封存区，不会自动返回战备区。

特殊形态、成长单位等可以拥有自己的返回规则。

---

# 6. 对局准备

双方随机决定先后手。

每名玩家抽取4张起始手牌，然后进行一次调度。

玩家可以选择任意数量的起始手牌换掉，再抽取相同数量的卡牌。

调度结束后，被换走的卡牌重新洗入主牌组。

先手玩家开始第一回合。

先手第一回合不抽牌。

后手第一回合正常抽牌。

---

# 7. PP系统

PP分为两个数值：

* 当前PP。
* PP容量。

二者需要始终分开处理。

---

## 7.1 PP容量

PP容量决定一个玩家每回合正常能够拥有多少PP。

每名玩家的PP容量从0开始。

自己每个回合开始时：

> PP容量增加1。

PP容量没有上限。

因此，对局可以自然进入：

* 10PP。
* 12PP。
* 15PP。
* 20PP。
* 更高数值。

高于10费的卡牌属于正常设计空间，而不是例外。

---

## 7.2 当前PP

当前PP是玩家本回合实际可以支付的资源。

自己回合开始时：

1. PP容量增加1。
2. 当前PP恢复至PP容量。

例如：

> PP容量为7。
> 回合开始后容量增加至8。
> 当前PP恢复为8。

普通卡牌费用只减少当前PP，不影响PP容量。

未使用的当前PP不会保留到下一回合。

---

# 8. 动用未来

玩家可以牺牲PP容量，以换取当前回合的额外行动。

每名玩家每回合默认只能**动用未来一次**。

目前有两种动用未来的方式：

* 预支。
* 燃耗。

一次卡牌行动同时发生预支和燃耗时，只计算为一次动用未来。

---

# 9. 预支

预支是所有玩家都可以使用的基础规则。

当玩家准备从手牌使用一张卡，但当前PP不足时，可以选择预支。

## 预支流程

假设玩家拥有：

> 当前PP：5
> PP容量：5

准备使用一张8费卡。

正常无法支付。

选择预支后：

1. 支付全部5点当前PP。
2. 尚缺3点费用。
3. PP容量减少3。
4. 卡牌正常使用。

结果：

> 当前PP：0
> PP容量：2

下一回合开始时：

> PP容量从2增加至3。
> 当前PP恢复为3。

如果没有进行预支，这一回合结束后下一回合原本应该拥有6PP。

因此，这次预支让玩家长期落后3点成长。

---

# 10. 预支限制

预支遵守以下规则：

1. 每回合默认只能使用一次。
2. 只有当前PP不足时才能使用。
3. 必须先支付所有剩余当前PP。
4. 只能补足一张卡实际缺少的费用。
5. PP容量不能因此降低至0以下。
6. 支付完成后不会因为卡牌被反制而返还。
7. 普通费用减免会先计算，再决定需要预支多少。
8. 战备部署不能默认使用预支。
9. 主动能力不能默认使用预支。
10. 进化不能使用预支。

某张卡可以明确写明：

> 此卡不能通过预支使用。

也可以写：

> 部署此卡时可以预支。

这些属于卡牌本身的例外。

---

# 11. 超前与按期

从手牌使用卡牌时，如果使用了预支，该卡获得状态：

> **超前**

没有使用预支，则视为：

> **按期**

这两个状态只记录该次使用方式，本身没有默认额外效果。

卡牌可以读取这个状态。

例如：

> 按期：抽取1张牌。

或者：

> 超前：本回合可以攻击敌方单位。

并不是所有卡都需要拥有按期或超前效果。

多数卡牌仍然可以完全不在意这个状态。

---

# 12. 燃耗

部分卡牌会主动要求玩家牺牲PP容量。

统一写作：

> **燃耗X**

燃耗X的含义为：

> 支付此卡费用时，使自己的PP容量减少X。

例如：

> 1PP
> 燃耗1
> 对一个敌方单位造成4点伤害。

玩家即使拥有足够当前PP，也必须额外减少1点PP容量。

燃耗：

* 属于支付代价。
* 支付后不会返还。
* 不受普通费用减免影响。
* 会占用本回合一次动用未来机会。

---

# 13. 预支与燃耗同时发生

一张卡可以同时：

* 当前PP不足，需要预支。
* 自身又拥有燃耗代价。

例如：

> 当前PP：3
> PP容量：6

使用：

> 5PP
> 燃耗1

玩家需要：

1. 支付3点当前PP。
2. 预支2点。
3. 再支付燃耗1。
4. PP容量总计减少3。

结果：

> 当前PP：0
> PP容量：3

这整个过程只算一次动用未来。

如果PP容量不足以支付全部预支和燃耗，则不能使用该卡。

---

# 14. 裂痕

每次因为预支或燃耗失去PP容量时，会产生相同数量的裂痕。

例如：

> 预支3 → 产生3个裂痕。

裂痕记录玩家本局尚未补回的未来资源。

自然回合成长不会自动消除裂痕。

例如：

> PP容量2
> 裂痕3

下回合开始：

> PP容量3
> 裂痕仍为3

裂痕不会直接产生额外负面效果，但可以被卡牌读取。

例如：

> 若你没有裂痕，获得额外效果。

或者：

> 每有一个裂痕，此卡费用减少1。

---

# 15. 修复

修复用于恢复曾经失去的PP容量。

统一写作：

> **修复X**

修复X：

1. 移除至多X个裂痕。
2. PP容量增加相同数量。

修复不能超过当前裂痕数量。

没有裂痕时，修复不会增加PP容量。

因此修复不等同于跳费。

修复PP容量时，当前PP不会增加，除非卡牌明确写明。

---

# 16. 增长

直接增加PP容量统一写作：

> **增长X**

增长X：

> PP容量增加X。

增长不需要裂痕。

因此：

* 增长是提前获得未来资源。
* 修复是补回已经失去的未来资源。

PP容量在自己回合中因为增长提高时，当前PP默认不会同时增加。

---

# 17. 当前PP高于PP容量

部分燃耗效果可能导致：

> 当前PP高于PP容量。

这是合法状态。

例如：

> 使用前：6当前PP／6容量。

玩家使用：

> 1PP，燃耗2。

先支付1当前PP：

> 5当前PP／6容量。

再燃耗2：

> 5当前PP／4容量。

本回合仍然可以使用剩余5PP。

下回合开始时，当前PP会按照新的PP容量恢复。

---

# 18. 高费用卡牌

卡牌费用没有10费上限。

费用区间暂时按照以下方向理解：

|    费用 | 大致定位   |
| ----: | ------ |
|   0～3 | 前期行动   |
|   4～6 | 中期主力   |
|   7～9 | 大型单位   |
| 10～12 | 常规后期   |
| 13～16 | 超后期    |
| 17～20 | 终局级卡牌  |
|  20以上 | 特殊构筑目标 |

高费用卡牌不一定需要等到对应回合才能使用。

预支允许玩家主动提前进入高费用区间。

例如第10回合拥有：

> 10当前PP／10容量。

理论上可以预支使用一张20费卡。

支付后：

> 当前PP0。
> PP容量0。
> 裂痕10。

下回合开始时只有1PP。

这类行动代表玩家把之后大量回合的资源提前集中到现在。

---

# 19. 回合流程

每个回合分为：

1. 开始阶段。
2. 行动阶段。
3. 结束阶段。

---

## 开始阶段

依次进行：

1. 重置己方单位的攻击状态。
2. PP容量增加1。
3. 当前PP恢复至PP容量。
4. 抽取1张牌。
5. 处理“自己回合开始时”效果。
6. 重置本回合的“动用未来”次数。
7. 重置本回合的“主动进化”次数。
8. 重置本回合的“战备部署”次数。

先手第一回合跳过抽牌。

---

## 行动阶段

玩家可以按任意顺序：

* 打出单位。
* 使用法术。
* 放置设施。
* 设置伏策。
* 进化单位。
* 发起攻击。
* 使用主动能力。
* 进行战备部署。
* 结束回合。

游戏没有固定战斗阶段。

玩家可以：

* 攻击后继续出牌。
* 出牌后攻击。
* 在不同单位的攻击之间使用其他卡牌。

---

## 结束阶段

依次进行：

1. 处理“自己回合结束时”效果。
2. 移除“直到回合结束”的效果。
3. 未使用的当前PP清零。
4. 结束回合。

---

# 20. 卡牌类型

当前版本拥有四种主牌组卡牌。

## 单位

单位拥有：

* 费用。
* 攻击力。
* 生命值。
* 职业。
* 种族或阵营标签。
* 能力。
* 进化后的状态。

单位生命降至0或以下时被破坏。

受到的伤害不会在回合结束时自动恢复。

---

## 法术

法术从手牌使用后立即结算。

结算完成后进入墓地。

---

## 设施

设施正面放置在策略区。

设施可以拥有：

* 持续效果。
* 主动能力。
* 回合触发。
* 倒计时。

设施不能正常攻击。

---

## 伏策

伏策背面放置在策略区。

设置时需要支付费用。

满足触发条件后，可以在响应窗口中发动。

发动并结算后进入墓地。

---

# 21. 单位战斗

单位刚刚登场的回合默认不能攻击。

卡牌可以拥有允许立即攻击的能力。

目前区分两种效果：

> 本回合可以攻击敌方单位。

以及：

> 本回合可以攻击。

后者同时允许攻击单位和主战者。

正式关键词之后再确定。

---

## 攻击条件

单位满足以下条件时才能攻击：

* 攻击力大于0。
* 本回合尚未攻击。
* 没有受到不能攻击的效果。
* 从自己本回合开始时已经存在于己方场上，或拥有允许立即攻击的能力。

单位默认每回合只能攻击一次。

---

## 单位之间的战斗

单位攻击单位时，双方同时造成等同于自己攻击力的伤害。

例如：

> 4/4攻击3/5。

结算后：

* 3/5受到4点伤害，剩余1生命。
* 4/4受到3点伤害，剩余1生命。

---

## 攻击主战者

攻击主战者时，只有攻击单位造成伤害。

主战者不会反击。

---

## 攻击目标离场

攻击宣布后会开启响应窗口。

如果攻击目标在战斗伤害发生前离场：

* 本次攻击结束。
* 攻击单位仍视为已经攻击。
* 不重新选择攻击目标。

---

# 22. 进化系统

进化属于所有职业共享的基础战斗系统。

## 进化能量

每名玩家拥有最多4点进化能量。

进化能量不会在回合结束时清空。

---

## 解锁时间

先手：

> 自己第五回合开始解锁进化，并获得2点进化能量。

后手：

> 自己第四回合开始解锁进化，并获得3点进化能量。

---

## 主动进化

主动进化一个单位消耗：

> 2点进化能量。

每回合最多主动进化一次。

同一个单位只能进化一次。

刚刚登场的单位也可以进化。

---

## 进化效果

单位进化后：

* 变为自己的进化状态。
* 攻击力和生命按照卡牌上的进化数值变化。
* 触发“进化时”效果。
* 本回合可以攻击敌方单位。

进化本身不会让单位立刻攻击主战者。

没有独立进化数值的普通单位，暂时按：

> +2攻击／+2生命

处理。

---

# 23. 职业进化条件

进化能量并非整场只有最初的几次。

每个职业拥有自己的进化充能条件。

从一个自己的回合开始，到下一个自己的回合开始之前，称为一个：

> **回合周期**

每个回合周期中，职业条件最多提供1点进化能量。

即使条件完成多次，也只获得一次。

职业条件必须来自该职业原本就想做的事情。

---

## 暂定例子

死亡类职业：

> 每个回合周期限一次。第二个己方单位被破坏后，获得1点进化能量。

法术类职业：

> 自己回合结束时，若本回合使用过至少两张法术，并且没有打出单位，获得1点进化能量。

大型单位类职业：

> 每个回合周期限一次。第一个原始费用5以上并完成战斗后仍存活的己方单位，使你获得1点进化能量。

以上只是模板，并非最终职业设计。

---

# 24. 战备区

战备区是一套公开的备用卡牌。

战备牌不必全部是大型终结单位。

可以包括：

* 前中期工具。
* 职业核心。
* 防守单位。
* 终结单位。
* 特殊形态。

主牌组本身也允许拥有高费用大型单位。

战备区的优势在于：

> 稳定、公开、可以根据场面主动选择。

因此战备牌的单卡强度不能同时高于普通主牌组卡，又没有额外代价。

---

# 25. 战备部署

每张战备牌必须写明：

* 部署条件。
* 部署费用。
* 部署代价。
* 所使用的资源或卡牌。
* 相关卡牌离场后的去向。

不为不同部署方式预先划分固定类别。

例如：

> 部署条件：己方场上存在两个机械单位。
> 部署费用：2PP。
> 部署代价：封存其中一个单位。

或者：

> 部署条件：本回合已使用三张法术。
> 部署费用：3PP。

两者在规则上都只是战备部署。

---

## 部署流程

1. 选择一张战备牌。
2. 检查部署条件。
3. 选择需要支付的卡牌或资源。
4. 支付部署费用。
5. 支付其他部署代价。
6. 战备牌登场。
7. 处理其登场效果。

部署代价支付后不会返还。

---

## 部署次数

每名玩家每回合默认只能进行一次战备部署。

卡牌可以明确写：

> 此次部署不计入本回合部署次数。

这种效果应该较少出现。

---

## 战备牌离场

普通战备牌离场后进入封存区。

默认不会：

* 返回手牌。
* 进入主牌组。
* 进入墓地。
* 回到战备区。

特殊形态可以拥有自己的规则。

---

## 战备部署与预支

战备部署不能默认使用预支。

如果某个系列希望围绕透支未来召唤战备单位，需要在卡牌上明确写明。

---

# 26. 响应系统

游戏允许双方在关键行动中进行即时互动，但不采用无限长度的连锁。

一次响应最多三层。

---

## 可以开启响应的事件

目前包括：

* 使用法术。
* 发动主动能力。
* 单位的登场效果准备结算。
* 单位宣布攻击。
* 卡牌明确写明的特殊时机。

以下动作默认不会单独开启响应：

* 抽牌。
* PP自然增长。
* 支付费用。
* 支付预支。
* 支付燃耗。
* 获得进化能量。

---

## 响应流程

1. 一方发动原效果或宣布行动。
2. 对方可以进行一次响应。
3. 原发动者可以进行一次反制响应。
4. 不再继续追加。
5. 按后加入者先结算。

即：

> 原行动 → 响应 → 反制

最长三层。

---

## 可以响应的卡牌

首版允许：

* 已设置的伏策。
* 场上明确拥有响应能力的卡牌。
* 明确允许在响应中使用的特殊效果。

普通法术不能在对手回合随意从手牌使用。

---

# 27. 效果结算

一个效果开始结算后必须完整处理。

不能在效果文本中间插入新的卡牌或能力。

如果结算过程中产生新的触发效果，会在当前效果完整结束后处理。

---

## 成本

卡牌支付的：

* PP。
* 预支。
* 燃耗。
* 弃牌。
* 封存。
* 生命。
* 其他明确写明的代价。

均属于成本。

成本支付后不会因为效果失效而返还。

---

## 目标失效

如果一个效果选择了目标，而目标在结算前已经离场或变得不合法，则针对该目标的部分失效。

其他仍然合法的部分继续结算。

---

# 28. 同时发生

多个单位因为同一次效果或战斗生命降至0时，同时被破坏。

多个效果同时触发时：

1. 当前回合玩家决定自己的触发顺序。
2. 对方决定自己的触发顺序。
3. 当前回合玩家的效果先处理。
4. 对方效果随后处理。
5. 当前批次结束后，再检查新触发。

---

# 29. 职业与系列

职业负责游戏的大方向。

系列负责具体玩法。

## 职业负责

* 职业卡池。
* 主战者。
* 进化充能条件。
* 大致资源风格。

## 系列负责

* 战备区如何使用。
* 特殊计数。
* 透支或修复玩法。
* 成长路线。
* 生死状态。
* 特殊胜利。
* 特殊部署条件。

同一个职业可以拥有多个玩法完全不同的系列。

因此不要求每个职业都拥有一套独立召唤系统。

---

# 30. 成长机制

成长不属于基础规则。

它是部分系列可以使用的机制。

目前保留两种数值。

## 成长值

属于养成玩家自己的进度。

负责决定：

> 什么时候能够进入下一阶段。

例如：

* 3点解锁第一阶段。
* 6点解锁最终阶段。

成长值不会被普通通用卡轻易归零。

---

## 环境值

环境值是双方都可以改变的共享数值。

它负责决定：

> 成长时有哪些路线可选。

例如：

| 环境值 | 可选择形态   |
| --- | ------- |
| 负数  | 防御、净化方向 |
| 中立  | 平衡方向    |
| 正数  | 攻击、混沌方向 |

环境值不应该直接替成长玩家决定最终形态。

更适合的处理方式是：

> 环境值决定可以选择的几个分支，再由成长玩家自己决定。

---

## 蜕变

成长单位改变形态称为：

> 蜕变

蜕变和基础进化不是同一件事。

进化属于通用战斗系统。

蜕变属于成长系列自己的形态变化。

---

# 31. 组件能力

素材为战备牌附加能力的设计保留，但只属于适合它的系列。

例如机械、构装、改造一类卡组。

拥有组件能力的卡牌可以写：

> 组件：以此卡支付部署代价时，登场单位获得某项能力。

默认规则：

* 一次部署最多获得一个组件能力。
* 特殊王牌最多两个。
* 后来获得的组件能力不能再次传递。
* 普通组件不能提供大范围清场。
* 普通组件不能提供额外战备部署。
* 普通组件不能无条件提供直接攻击主战者的能力。

组件是系列机制，不是所有单位都必须拥有的系统。

---

# 32. 生者与死者状态

部分死亡类系列可以让同一张卡在不同区域拥有不同状态。

例如：

* 在手牌和场上时为生者。
* 被破坏进入墓地后切换为亡魂。
* 亡魂可以拥有一次墓地能力。
* 使用后进入封存区。

普通单位不需要全部拥有两套能力。

大多数单位仍然可以只使用正常遗言。

---

# 33. 牌组耗尽

玩家需要抽牌但主牌组中已经没有卡牌时，会受到疲劳伤害。

第一次：

> 1点。

之后依次增加：

> 2、3、4、5……

如果一次效果需要抽多张牌，每一张无法抽取的牌分别触发一次疲劳。

围绕空牌组构筑的系列可以修改这项规则，但必须通过卡牌或系列效果明确说明。

---

# 34. 规则用语

以下词语拥有固定规则意义。

| 用语   | 含义                    |
| ---- | --------------------- |
| 打出   | 从手牌支付费用使用卡牌           |
| 登场   | 单位以任何方式进入单位区          |
| 部署   | 从战备区让卡牌登场             |
| 进化   | 使用进化能量改变单位状态          |
| 蜕变   | 成长单位更换为另一种特殊形态        |
| 破坏   | 单位因战斗或效果进入墓地          |
| 离场   | 卡牌从场上前往其他任何区域         |
| 封存   | 正面离开正常卡牌循环            |
| 支付   | 作为成本，支付后不能返还          |
| 预支   | 用PP容量补足手牌费用           |
| 燃耗   | 卡牌主动要求减少PP容量          |
| 裂痕   | 记录尚未补回的PP容量损失         |
| 修复   | 消除裂痕并恢复容量             |
| 增长   | 直接提高PP容量              |
| 超前   | 使用预支打出的卡牌             |
| 按期   | 没有使用预支打出的卡牌           |
| 原始费用 | 卡牌本身印刷的费用             |
| 当前费用 | 受到效果改变后的实际费用          |
| 回合周期 | 从自己的一个回合开始到下一个自己的回合开始 |

卡牌文字必须按照这些规则术语书写。

风味描述与规则文字分开。

---

# 35. 当前版本暂时不加入的内容

以下内容不属于v0.4基础规则：

* 固定的融合、仪式、共鸣等召唤分类。
* 每个职业都有不同的底层召唤规则。
* 每个职业都有特殊胜利。
* 完整无限连锁。
* 对手回合随意从手牌施放大量法术。
* 一回合反复进行战备部署。
* 所有卡牌拥有双模式进化。
* 所有单位都拥有组件能力。
* 所有单位都拥有生死两套状态。
* PP容量固定封顶10。
* 普通低费卡永久削减对方PP容量。
* 大量0费抽牌与0费检索。
* 能够利用预支形成无限循环的效果。
* 开局随机获得改变整局规则的强力效果。

这些设计以后可以作为：

* 单独系列。
* 单张卡。
* 特殊模式。
* PvE玩法。
* 活动规则。

---

# 36. 首版测试牌组

第一轮原型仍然只做两副固定牌组。

## 常规中速牌组

用于测试：

* PP曲线。
* 正常单位交换。
* 进化。
* 战备区。
* 伏策。
* 短响应。
* 预支什么时候值得使用。

这副牌不刻意利用大量燃耗和修复。

它作为正常对局基准。

## 预支牌组

第二副牌围绕未来资源展开。

主要测试：

* 提前使用高费牌。
* 燃耗低费牌。
* 裂痕。
* 修复。
* 按期与超前效果。
* 对手如何惩罚过度预支。

这副牌不需要同时加入成长、组件、生死状态等其他复杂机制。

---

# 37. v0.4目前最重要的测试问题

原型阶段优先观察：

1. 玩家是否真的会纠结“现在预支还是以后再出”。
2. 预支几费以后开始明显危险。
3. 激进牌组是否能够无视未来，靠预支直接结束比赛。
4. 预支失败一次是否会直接导致游戏失去翻盘可能。
5. 修复牌是否过于容易抹掉预支代价。
6. 20费以上卡牌是否真的存在不同的出场路线。
7. 当前PP和PP容量两个数字是否容易理解。
8. 裂痕UI是否能够让玩家快速判断双方的未来资源。
9. 进化是否能让预支后的低PP回合仍然有操作空间。
10. 战备区是否因为不能正常预支而和手牌形成明确区别。

---

# 38. 当前版本的核心规则

v0.4的游戏核心可以暂时总结为：

> PP容量会随着对局持续增长，没有固定上限。

> 玩家不必等待费用自然到达。当前PP不足时，可以预支未来的PP容量，提前使用手中的高费用卡牌。

> 每一次预支都会留下裂痕。现在得到的强度，会直接减少未来几个回合的行动空间。

> 部分卡牌还可以主动燃耗PP容量，也可以通过修复补回已经失去的未来资源。

> 进化作为独立的战斗资源存在，并且可以通过职业玩法重新积累。

> 战备区提供公开且稳定的额外选择，但默认不能依靠预支提前调用，从而与手牌形成区别。

> 成长、环境值、组件、生死状态等机制属于卡组系列，可以围绕基础规则展开，但不强迫整个游戏一起使用。
