## 1. 原创与 clean-room 原则

目标是原创的日式幻想动漫商业卡牌插画：清晰人物剪影、精致服装与器物、戏剧化光照、可读的动作和统一世界观。
《Shadowverse》的公开资料只用于规则术语理解，不能作为逐图构图、角色、画风临摹或素材来源。

后续生产必须遵守：

- 不复制或变体重画《Shadowverse》、YGOPro2、Yu-Gi-Oh! 或其他作品的角色、姿势、构图、卡框、纹章、Logo、UI、素材或文案；
- prompt 不使用在世艺术家姓名，也不要求“某作品同款”；只描述原创世界观、媒介、光线、镜头和角色特征；
- 插画中不烘焙名称、费用、攻防、规则文字、职业字样、Logo、水印或伪签名；这些由卡框和 UI 排版；
- 不使用现有动漫角色的发型＋服装＋配色组合，不描摹本地参考截图；每个主要角色拥有可辨识的原创轮廓和道具；
- 卡背不得出现眼形、旋涡、千年神器式几何或游戏王卡背的比例／线框细节；
- 不以现有 29 张 Gate 4B 科幻临时卡图或同清单中的卡背、菜单背景、fallback 与头像改色冒充新系列；未来实现按资产清单彻底替换旧产品美术；
- 内容保持适合青少年：不以性化身体、血腥肢解、仇恨符号或现实宗教图标作卖点。

每个最终文件都必须进入资产清单，记录设计编号、路径、像素尺寸、色彩空间、生成／绘制方式、日期、完整 prompt、
人工修改说明、SHA-256 和授权声明。未知来源、缺记录或重复哈希的文件不得进入产品导出。

## 2. 通用制图规格

### 2.1 卡牌插画

- 34 张可构筑卡与 1 张衍生物各有一张独立原创母图；建议母图至少 2048×3072，2:3 竖构图、sRGB。
- 角色／机体主体集中在中部 60% 安全区，头部和关键武器避开左上费用及下方身材徽章；缩至手牌尺寸仍能辨识。
- 随从以单一主体和明确姿态为主；法术强调一瞬间的动作因果；护符强调可留场的物件；场地使用宽阔纵深；伏策强调蓄势而非已发生结果。
- 背景细节服务轮廓，不用同明度噪点淹没人物。亮区与暗区必须能承受 1280×720 下的小卡裁切。
- 同名人物若未来再次出现，应沿用角色设定表，但本轮每个设计编号仍对应唯一构图，不复用裁切图。

### 2.2 主战者

- 两名主战者各制作一张高分辨率全身／半身兼容母图，建议 3072×4096；预留 1:1 头像、3:4 详情和 16:9 对局演出的安全裁切。
- 面部、发型、服装层级、主武器／契书、正侧背色稿和表情表在正式生产前建立 turnaround；同一角色在菜单与对局中不得漂移。
- 主战者只承载视觉身份，不暗示不存在的主动技能。

### 2.3 统一卡背

- 一张双方共享的 2:3 卡背母图，建议至少 2048×3072；上下旋转后仍协调，但须能通过外框方向辨别朝向。
- 中央纹章是“金银双环围绕日轮，日轮被一条紫色裂隙贯穿”；深靛底，边缘使用原创细密誓约刻线。
- 不出现职业文字或角色，因此隐藏手牌、牌组和伏策始终使用同一张无身份材质。

## 3. 阵营视觉语言

### 3.1 誓卫／曜誓骑士团

- **主色**：象牙白、铂金、苍蓝；**强调色**：温暖日轮金；阴影偏冷蓝紫而非纯黑。
- **形状**：完整圆环、上升弧线、对称披风、层叠盾面、日晕和钟形结构；表达秩序、兑现与修复。
- **材质**：细拉丝白金、蓝珐琅、半透明誓光晶体、洁净织物。盔甲要轻盈庄严，不做现实中世纪军团复刻。
- **人物气质**：克制、可靠、互相支援；动作有重量但不笨重。无隙／屏障以闭合光环和完整光膜表现。

### 3.2 契术／渊契魔导院

- **主色**：黑紫、墨蓝；**强调色**：绯红、洋红、债务金；亮部可用冷白纸张形成强对比。
- **形状**：断裂圆、悬浮纸页、不对称束带、分叉裂隙、刻度和层叠契约；表达借取未来和精确操纵风险。
- **材质**：黑曜玻璃、紫黑布、金属书脊、发光墨水、红紫能量裂口。危险感来自失控边缘，不靠血腥或恶魔套板。
- **人物气质**：聪明、主动、略带挑衅；每次燃耗／负契应看到“收益已经拿到、代价仍留在身后”。

### 3.3 共享中立

- 使用石灰白、旅行皮革、雾青和暖橙火光；构图更接近日常边境与跨界裁定，不偏向任一职业。
- 中立卡可以与两方画面并置，但不得偷偷使用日轮骑士团徽章或渊契院章。

## 4. 主战者设定锁定

### VIS-36：曜誓圣王女·奥蕾莉亚

成年女性，金白长发，苍蓝眼睛；白金分层盔甲兼具王族礼服轮廓，肩后展开非宗教性的日轮披风，
武器为细长誓约剑与可闭合的环形护手。站姿稳定、目光冷静，手势像是在接受并确认承诺，而非高声煽动。
主光为晨曦金，轮廓光为苍蓝。禁止王冠堆砌、圣女模板化祈祷姿势或与现有动漫角色相似的发饰。

### VIS-37：渊契院长·瑟蕾娅

成年女性，紫黑长发，绯紫眼睛；不对称魔导院制服由短披肩、长尾外套和细金属束带构成，身侧漂浮多本无文字契书，
右手操纵一条紫红裂隙。表情危险、自信、完全清楚代价。逆光为洋红，脸部保留冷白书页反光。
禁止女巫帽、照搬学院制服、恶魔角和性化暴露剪裁。

同职业双方可使用相同主战者视觉；席位、姓名和活动光环由 UI 区分，不为此增加第三张头像资产。

## 6. 卡框与 UI 接入约束

卡框与 UI 不计入上述 38 张插画，但后续视觉 Gate 必须单独设计原创组件：

- 随从、法术、护符、伏策、场地有一眼可辨的类型符号；职业归属由边框材质与小纹章表达，中立使用独立边框；
- 费用、攻击、生命和倒数使用程序化文字／矢量徽章，不写进插画；0 攻或 0 血等合法数值不能因 falsy 判断消失；
- 手卡缩略时优先保留费用、类型和单位身材，完整名称／规则由详情面板显示；
- 隐藏牌 actor 只能绑定 `VIS-38`，不得预加载或保留 definition-specific 纹理、metadata、tooltip 或 shader 参数；
- 主战者头像可由同一母图裁切，不增加资产计数；相同职业的两席使用同图，通过 UI 席位标签区分；
- 阵营色是信息冗余而非唯一提示，合法目标、选中、守护和屏障仍需轮廓、符号或动画共同表达。

## 7. 后续美术验收

在未来实际生成／绘制 38 项资产后，必须逐张完成：

1. 人工 clean-room 审查：无明显既有 IP 角色、构图、卡框、Logo 或商标视觉；
2. 文件审计：唯一设计编号、唯一内容哈希、完整来源与 prompt 记录；
3. 缩略可读性：1280×720 手牌与场上尺寸仍能辨认主体；费用／身材由卡框正确显示；
