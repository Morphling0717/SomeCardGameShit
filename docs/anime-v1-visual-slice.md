# Gate 6A：AnimeV1 原创动漫视觉样片

> 状态：`slice_candidate_pending_user_approval`
>
> 这是一条完全不访问 native 的独立视觉验收入口。它不会把 Gate 5B 的运行时底座冒充成两副新牌已经可玩。

## 本轮交付

样片把整个产品的长期视觉方向锁为原创华丽厚涂日式幻想动漫风，并用真实 Godot 2.5D 构图验证以下八个状态：

- 无文字菜单主视觉；
- 誓卫／契术牌组设置；
- 普通行动战场；
- 相机相对扇形手牌悬停；
- 五格混合永久物、三格策略区和独立场地格；
- 响应浮层；
- 完全不透明的热座交接页；
- 结果页。

本轮共有 14 项 raster 候选：两张透明主战者母图、七张代表卡、两张王牌进化异画、一张统一卡背、一张菜单主视觉和一张开放式幻想竞技场。精确路径、哈希、用途和生成摘要见 AnimeV1 素材清单；完整 prompt 与修改记录见同目录的 PROVENANCE.md。

## 视觉约束

- 固定斜视 2.5D 直操、相机相对手牌和点击／拖拽节奏继续保留；
- 战场是开放竞技场，不绘制包围所有格位的外围桌框；
- 随从、法术、护符、伏策和场地拥有不同程序化卡框与类型标记；
- 名称、费用、身材、倒数和规则文字由 Godot 绘制，不烘焙进插画；
- 隐藏牌只使用统一卡背，不能带 definition、instance ID、私有材质或 tooltip；
- 曜誓使用象牙白／铂金／苍蓝／日轮金，渊契使用黑紫／墨蓝／绯红／裂隙洋红；公共 UI 使用月白／深靛／旧金；
- 动漫化完成后 AnimeV1 是唯一产品视觉；旧科幻、工业和黑蓝玻璃素材不作为长期双皮肤保留。

交互查看时，两名主战者具有约 4.2 秒的轻量呼吸、受限鼠标视差和入场切入；行动／混合永久物页可触发受击脉冲，结果页区分胜者光环与败者压暗。`Covered` 永远保持完全不透明且不播放角色动效。自动截图目录模式会关闭上述时间相关动效，因此同输入可以得到稳定、可比较的取证图片。

完整 38 项主体美术及品牌、菜单、竞技场、卡框、HUD、弹层、VFX、字体、fallback 和 shader 的切换条件记录在 design/product-decks-v1/anime-v1-visual.lock.json。

## 本地查看

Godot 编辑器或导出程序可附加参数：

    --anime-style-slice

进入无 native 的可交互样片。自动截图使用绝对目录：

    --anime-style-slice=<absolute-directory> --anime-style-slice-exit

也可用 `--anime-style-state=<state>` 选择 `menu`、`setup`、`action`、`hand-hover`、`mixed-permanents-field`、`reaction`、`covered` 或 `result`。自动矩阵脚本在 Windows 与 macOS 上分别捕获 1280×720、1600×900、2560×1440 和 2560×1600，共 32 张图，并让验证器检查八态完整性、无外围桌框、五种卡面、隐藏牌无身份和 Covered 不透明。

正式导出包提供显式入口：Windows 必须先完整解压 ZIP，再双击 `PLAY_ANIME_STYLE_SLICE.cmd`；macOS 解压后执行或双击 `PLAY_ANIME_STYLE_SLICE.command`。不要只把启动器单独拖出包。启动器与导出程序同目录，只传固定的无 native 样片参数；CI 会从原始导出和 ZIP 解包结果分别启动一次并核对八态报告。默认双击游戏 EXE／APP 仍进入过渡期旧产品路径，不会因为样片存在而提前切换。

AnimeV1 专属说明、完整生成记录和素材清单分别随包放在 `licenses/ANIME_V1_SLICE_README.md`、`licenses/ANIME_V1_PROVENANCE.md` 和 `licenses/ANIME_V1_ASSET_MANIFEST.json`。同一可执行文件仍与过渡期 R2 产品包共用，因此通用 `BUILD_INFO.txt` 保持 `Gate 4B-R2`；AnimeV1 样片身份以专属启动器和上述三份逐字节审计文件为准，这不表示 AnimeV1 属于 R2 或已经成为默认产品路径。

## 第一轮人工验收

样片顶部按钮可以直接切换八种状态；在 `action`／`mixed-permanents-field` 页使用“主战者受击”演示，在 `setup`／`result` 页移动鼠标查看轻量视差。审批时请分别判断两名主战者、七张代表卡、统一卡背、开放竞技场、五类卡框与数字可读性、HUD／弹层以及轻量动效。特别检查 `AP-11` 前伸的爪／手是否清楚，以及 LO-11、AP-11 的普通图与进化异画在手牌缩略尺寸下是否足够容易区分。

可以直接回复“整体批准”，或按 `visual_id：需要修改的点` 列出返工项；后续只会批量扩展明确获批的方向。

## 批量生产闸门

只有用户明确批准这轮人物、卡图、卡背、竞技场、卡框和 HUD 的整体方向后，才进入 Gate 5C／6C：把 34 张可构筑卡与 1 个衍生物接成完整产品内容，并批量制作尚缺的 27 张构筑卡图、1 张衍生物图和剩余演出资源。普通随从进化复用原图；只有 LO-11 与 AP-11 使用独立进化异画。

本样片通过只能证明视觉方向与渲染契约成立，不能证明新牌效果、胜率、节奏或完整对局已实现。
